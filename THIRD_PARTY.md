# Third-party software

This project contains the pipeline adapters and generation code; these external frameworks and their weights are not vendored:

- [Pointcept](https://github.com/Pointcept/Pointcept): PTv3 semantic segmentation.
- [OpenPCDet](https://github.com/open-mmlab/OpenPCDet): TransFusion-L detection and CUDA operations.
- [MCTrack](https://github.com/megvii-research/MCTrack): tracking.
- [KISS-ICP](https://github.com/PRBonn/kiss-icp): LiDAR odometry.
- Open3D, NumPy, SciPy, PyTorch, Numba, OpenCV and other packages listed in requirements.

Each repository, package, dataset and checkpoint retains its own license and usage terms. Obtain weights and datasets from their authorized sources. This package does not grant rights to third-party checkpoints or data. See docs/INSTALL.md for tested source revisions.
